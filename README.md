# BLOOMIE 🌸

BLOOMIE is a gamified emotional learning web application designed for children.  
The platform helps kids practice empathy, emotional reflection, kindness, and decision-making through interactive real-life scenarios.

Users can:
- Read emotional scenarios
- Choose actions
- Write reflections
- Receive AI-powered emotional feedback from AURA
- Track emotional growth and progress
- Allow parents to monitor learning activity through a dashboard

---

# 🌟 Features

## 🎭 Interactive Emotional Scenarios
Children are presented with real-life situations that encourage empathy and emotional intelligence.

Example:
- A classmate sitting alone during lunch
- Breaking something at home
- Helping a sad friend

---

## 🤖 AURA Emotion Assistant
AURA analyzes children's written reflections and detects emotions such as:
- Empathy
- Kindness
- Sadness
- Happiness

Then it returns warm and encouraging feedback.

---

## 📖 Reflection Journal
Children can write reflections explaining:
- Why they made a choice
- How they felt
- What they learned

Reflections are stored in the database.

---

## 👨‍👩‍👧 Parent Dashboard
Parents can monitor:
- Total reflections
- Emotional progress
- Recent reflections
- Detected emotions
- Earned badges and progress levels
